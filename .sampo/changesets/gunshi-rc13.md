Upgrade gunshi and `@gunshi/plugin-completion` to 1.0.0-rc.13. Human `--help` now shows option values as `<name>` (`--out <out>`), names the options a command requires in its usage line and in the program's command list (`normalize --out <out> <input>`), and ends with a single `slicewright <COMMAND> --help` pointer. Parsing, error messages, exit codes, agent mode, the `commands` JSON catalog, and shell completion are unchanged.
